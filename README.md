## 📌 About The Repository

This repository serves as a structured learning resource for Deep Learning and Artificial Intelligence.

It contains theoretical explanations, practical implementations, visualizations, and notes covering topics from basic neural networks to modern Large Language Models (LLMs).

The objective is to provide a single place where students, researchers, developers, and AI enthusiasts can learn, practice, and explore Deep Learning concepts through code and examples.

---

## 🎯 Learning Objectives

After exploring this repository, you will be able to:

* Understand the fundamentals of Deep Learning
* Build and train Artificial Neural Networks
* Work with Convolutional Neural Networks (CNNs)
* Understand Recurrent Neural Networks (RNNs), LSTMs, and GRUs
* Learn the Attention Mechanism
* Understand Transformer Architecture
* Explore BERT, GPT, and Large Language Models
* Apply Deep Learning concepts to real-world problems

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sarvesh457/Deep-Leaning.git
```

### Navigate to the Project Directory

```bash
cd Deep-Leaning
```

### Create a Virtual Environment

```bash
python -m venv venv
```

### Activate the Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
